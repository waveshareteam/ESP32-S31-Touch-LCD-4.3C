# 构建验证记录

[English](validation.md)

本页保留 2026-10-30（Asia/Shanghai）的历史验证结果，不代表当前分支提交已通过 CI。

## 工具链与依赖

16 个示例当时均使用 ESP-IDF 提交 08e0d30a74ad0bfd5a34933142b80f45619ee410 编译成功。解析到 waveshare/waveshare_boards 0.1.3、esp_board_manager 0.7.5 及 esp_codec_dev 2.0.0-beta5；三个 adapter 示例固定 0.6.0，四个 LVGL 示例固定 9.5.0。

当时的板包尚未包含本板，隔离构建使用已准备的板型作为验证夹具；生产 CI 没有本地复制回退，要求组件发布包包含本板。该历史情况不应推断为当前注册表状态。

## 显示与音频

综合测试带有 ES8389 麦克风时钟修正并编译成功：双 16 位时隙使用 32fs BCLK，应用检查总线及源时钟后修改并读回 0x05、0x06、0x07、0x09 寄存器。LVGL 9.5 渲染验证了 800 × 480 屏幕中的双声道电平、页脚日志和页头汇总布局。

## 发布工具

隔离验证构建了全部 16 个示例，固件包通过完整矩阵、图像头、偏移、填充、烧录参数、摘要、依赖版本及板级哈希检查。保留了 ESP32-S31 的 --no-stub；未烧录开发板。

发布工具测试覆盖异常或移动标签、默认分支可达性、损坏或缺失产物、依赖漂移、草稿重试、远端摘要失败及拒绝覆盖公开版本。两个工作流当时通过 actionlint，通用打包冒烟检查通过；远端上传和发布使用模拟 API，没有实际发布 Release。

## SDMMC 4-bit 后续验证

首次全量构建使用 1-bit，随后共享板级定义改为 4-bit，使用 GPIO20–GPIO23 为 D0–D3、GPIO24 为 CLK、GPIO25 为 CMD。05、07、13 示例使用更新夹具及相同工具链重新编译成功，并检查生成配置中 bus_width = 4。

用户随后确认示例实板测试通过，包括 4-bit SDMMC；该确认与上述自动编译验证分开记录。随附机械文件仍为 ESP32-S3 参考资料。
