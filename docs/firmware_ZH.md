# 固件产物

[English](firmware.md)

## 随附测试镜像

[固件目录](../firmware/README_ZH.md) 中的 16 MiB 全 Flash 测试镜像是独立的预编译二进制，不是 examples/esp-idf 中的工程产物，没有随附源码或构建说明，也未确认为出厂恢复固件。文件大小及 SHA256 以固件目录说明为准。

烧录全 Flash 镜像会替换应用、分区和用户数据，请先备份，并使用明确支持 esp32s31 的烧录工具及板级流程。

## 源码构建产物

16 个 ESP-IDF 工程是仓库维护的源码固件。打包工具根据 flasher_args.json 生成带原始分段、合并镜像、清单、烧录助手及校验和的独立压缩包，详见 [发布说明](../releases/README_ZH.md)。

产物必须记录示例路径、准确工具链、目标 esp32s31、源码提交、分段偏移及生成时间。CI 产物只对应生成它的源码版本，不应被描述为随附测试镜像或出厂固件。
