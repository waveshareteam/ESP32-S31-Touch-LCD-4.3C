# Firmware Artifacts

This repository has two distinct firmware categories. They must not be mixed in
documentation, CI, or release uploads.

## Checked-In Test Image

`firmware/ESP32-S31-Touch-LCD-4.3C-Test.bin` is a 16 MiB test full-flash image
provided for board-level evaluation.

- It is a prebuilt binary, not an ESP-IDF source project.
- Its source and build instructions are not included under `firmware/`.
- It is not generated by the projects under `examples/esp-idf/`.
- It is not a CI output and must not be uploaded again as though CI built it.
- Its name does not establish it as a factory-recovery or production release
  image.


A full-flash image replaces partition data and user storage as well as the
application. Back up required device data before flashing. Use only a flashing
toolchain that explicitly supports ESP32-S31 and follow the board-specific
flash procedure supplied with that toolchain.

## Source-Built Example Artifacts

The 16 projects under `examples/esp-idf/` are the maintained source firmware.
A successful build may be packaged from its ESP-IDF `flasher_args.json` into a
separate flashable archive containing a manifest, flash helpers, original
segments, and a combined image. See `releases/README.md`.

Source-built archives must identify:

- example path,
- exact ESP-IDF package, tag, or commit,
- target `esp32s31`,
- repository commit,
- flash offsets and files,
- generation timestamp.

CI artifacts validate the source revision that produced them. They do not
replace the checked-in test image and must not be described as factory
firmware.

## Toolchain Requirements

Use ESP-IDF and flashing tools that support `esp32s31`. Record their exact
versions with the firmware package. This repository contains ESP-IDF examples
and has no Arduino sketches.
