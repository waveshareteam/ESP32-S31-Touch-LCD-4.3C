# QMI8658 IMU

[简体中文](README_ZH.md)

## What It Does

Reads QMI8658 identity, temperature, accelerometer, gyroscope and interrupt status.

## Hardware Required

Board and USB data cable.

## How to Run

Follow the [ESP-IDF instructions](../README.md#build-and-flash) to prepare the pinned toolchain, resolve dependencies, generate this project’s board configuration, then build and flash.

## Expected Result

Serial readings change as the board is tilted or rotated.

## Troubleshooting

None yet.
