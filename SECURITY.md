# Security Policy

Do not disclose a suspected vulnerability in a public issue before it has been
triaged.

Report security issues through a private channel listed on the Waveshare [support contact page](https://www.waveshare.com/contact_us) and include:

- the ESP32-S31-Touch-LCD-4.3C product and hardware revision,
- the affected repository path, example, or firmware artifact,
- the exact ESP-IDF package, tag, or commit,
- an impact summary and reproducible steps,
- relevant logs or proof of concept,
- any suggested mitigation.

Do not include access tokens, credentials, private keys, customer data, or
other secrets in the report unless an agreed secure transfer method is used.
For non-security defects, use the repository issue template.
